Before substantive work in every new task, resumed task, or context window:

1. Fetch and completely read the current canonical operating contract from `/Users/james/.agents/operating-contract/v2/OPERATING_CONTRACT.md`
2. Load and verify every mandatory companion declared by the contract. Use local files where possible.

Treat the freshly fetched contract document as authoritative. Re-fetch after a long pause, reset, canary lapse, drift warning, lost decisions, or suspected context degradation. If retrieval fails, state that before substantive work and ask whether James should paste the contract or continue with explicitly limited context.

Follow the contract, including its operating canary, claim tails, Focus Lock, tangent handling, progress gate, and copy-safe exclusions.

1. Read the current `WORKSTREAM-STATE.md` project/thread source. If one does not exist, create a durable WORKSTREAM-STATE by using the template at `/Users/james/.agents/operating-contract/v2/WORKSTREAM-STATE.md` keeping it tied to the thread id.

3. If the state source is missing or stale, say so plainly; do not silently reconstruct project state from general memory.
4. Keep Focus Lock ON unless James explicitly uses `UNLOCK FOCUS`.
