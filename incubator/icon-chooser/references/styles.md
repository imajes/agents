# Choosing a family

Run `styles` to see the installed distribution's exact family/weight coverage.
Run `styles ICON` to enumerate all real variants of one canonical icon. Do not
infer availability from another icon's family coverage. Families contain different
subsets of the library.

| Direction | Families to inspect | Good uses |
| --- | --- | --- |
| House | Duotone Light | Palette accents, reports, cards, illustrative headings |
| Angular | Sharp, Sharp Duotone | Technical systems, architecture, crisp layouts |
| Carved or engraved | Chisel, Etch | Crafted/editorial accents with substantial detail |
| Drawn | Graphite, Whiteboard | Teaching, brainstorming, informal explanatory artifacts |
| Soft and playful | Jelly, Jelly Duo, Jelly Fill, Notdog, Notdog Duo | Friendly consumer or child-facing material |
| Typographic | Slab, Slab Duo, Slab Press, Slab Press Duo | Editorial, print-inspired graphic moments |
| Graphic/texture | Mosaic, Thumbprint, Vellum | Expressive accents at display sizes |
| Retro digital | Pixel | Games, computing, intentional pixel-grid treatments |
| Compact/practical | Utility, Utility Duo, Utility Fill | Clear compact interfaces and dense information |
| Broad/familiar | Classic | Coverage gaps, conventional interface language |

These are selection cues, not universal prescriptions. Compare the actual artwork
at its final size. Fine lines and texture may need more space. At tiny sizes,
consider a heavier or simpler variant if the requested Light version loses detail;
explain that recommendation and preserve explicit user choices.

For a set of concepts, inspect each candidate's families and choose a shared
family where possible. A fresh house icon next to a Classic person can look
accidental; use one coherent direction or make a deliberate hierarchy such as
expressive section illustrations with simpler inline utility icons.

The house uses Duotone Light plus a complementary accent already in the artifact's
palette. A second hue at full opacity can be appropriate; a quieter tint at 40%
can work better in a dense layout. Inspect both on the actual background.

https://docs.fontawesome.com/web/dig-deeper/styles
