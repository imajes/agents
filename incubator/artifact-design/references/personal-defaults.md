# Personal presentation defaults

These are James's preferences when the current request leaves a design choice open. Respect a supplied template, explicit font choice, established design system, medium, and narrower edit scope. The case study records historical settings; it is not an additional universal template.

## Typography and emphasis

- Use Karla by default for body text in reports and similar reading artifacts.
- Choose headings deliberately. James approved Karla ExtraBold for the dossier title; that does not mandate one heading face or point size across all artifacts.
- Use real weights, bold, italics, and selective underlining to express hierarchy. Avoid relying only on size and color. Bold, underlined item names were requested for one compact contents table; apply that combination where it helps scanning, not to every name everywhere.
- Check actual rendered fonts rather than assuming a family declaration reached every heading, table, and export.

## Identifiers

When IDs are useful, explain them early and keep the key compact, one prefix per row. Prefer a narrow dedicated lookup column where appropriate; listing IDs in a pricing table should have their own column.

Make inline reference IDs small, bold, and visually distinct, generally in a subtle monospace pill with its text optically centered and the pill vertically aligned with surrounding text. Keep identifiers at no more than about 80% of the surrounding text size while maintaining readability. Reconsider how much metadata is displayed if that produces unreadable text. Do not invent an ID system for a small artifact that does not need one.

## Space, supporting notes, and quantities

Give major sections and action groups breathing room. Compact reference and index tables can use smaller type and tighter rows; a dense directory and an action card have different reading jobs.

Use callouts with recognizable purposes. Prices or other key decision values should be immediately distinguishable from preparation and supporting references when these roles exist.

A genuine footnote needs an inline link or marker, placement near the relevant footer where the format permits it, and a separate line for each note. Otherwise use a named References block explaining source usefulness, or an appropriate anchored endnote. Keep entries individually separated rather than concatenated with bars.

State the basis of money, counts, dimensions, and intervals. For inch measurements, compact notation such as `9"` is preferred to a clumsy `9 in` construction when the context is clear.

## Voice and reader effort

Address James naturally in a working document. Avoid referring to him as "the owner" in his own dossier. Public descriptions and technical roles may use different terminology when appropriate; this is not a ban on the word in all contexts.

Keep editing history, unnecessary internal bookkeeping, and explanations of obvious document controls outside the finished content. Use familiar, correct names and concise labels. Preserve qualifications that change a decision or action; avoid ornamental caveats.
