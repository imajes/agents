# Bundled assets

Complete original Font Awesome Free, Pro and Pro Plus 7.3.1 desktop ZIPs include their SVGs, OTF fonts, metadata and LICENSE.txt files. Compressed archives avoid expanding roughly 1.7 GB of overlapping files. Index and extraction work without a network or original-project path.

Karla includes Light 300, Regular 400, Medium 500 and true Italic 400 static fonts, original variable sources and SIL OFL 1.1. It is an adjustable default.

## Exact discovery

Search names and metadata keywords. Specify family and style independently: duotone/regular/head-side-speak, duotone/solid/puzzle, duotone/solid/key-skeleton, graphite/thin/fire. Never silently substitute a similar name or style. The desktop directory named duotone contains duotone solid; metadata confirms the style.

The vector renderer uses normalized svgs-full paths. An explicit secondary color replaces the original opacity layer with an opaque second color. Inspect contrast at actual icon size. Single-color families ignore secondary color. SVGs generally offer more semantic and two-color control for PDFs than icon-font glyphs, but every supplied OTF remains available.

## Licenses

Original license files remain inside each archive and in assets/fontawesome/licenses. Archive hashes and sizes are in manifest.json. Pro terms: https://fontawesome.com/license. Free terms: https://fontawesome.com/license/free.

The supplied Pro licenses require a paid license. Bundling the user's existing copies for private use does not grant a license to others. Do not publish these archives, extracted proprietary SVG/OTF sources, or the complete asset-bearing skill to a public repository, marketplace or broadly shared template. Check actual terms before source redistribution; use an appropriately licensed set for public distribution.

Free SVGs are CC BY 4.0; Free fonts are SIL OFL 1.1; other Free code is MIT. Preserve notices and extraction sidecars with editable projects. Brand icons represent the actual company/product/service, not generic decorative concepts.

## Storage and scope

Original archives total 324,306,722 bytes (309.3 MiB), plus fonts/index. The supported local skill-creator workflow specifies no bundle size cap. This does not establish a cloud or synced service's capacity. Check its real limits before transfer; never quietly replace these complete packs with a subset or machine-only path.
